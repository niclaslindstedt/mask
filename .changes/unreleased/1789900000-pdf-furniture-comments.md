type: Changed
title: A page's header and footer come through as comments
doc: pdf-markdown
---

A PDF's running header and footer are no longer dropped: they come through as HTML comments (`<!-- HÖGSTA DOMSTOLEN B 4808-23 Sida 2 -->`) where they were drawn, so the model you hand the text to can still tell which page a passage came from without mistaking the page-number bar for a sentence — shown as a muted aside when you read the document, and left off a PDF you download.

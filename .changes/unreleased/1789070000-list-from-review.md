title: Blacklist and whitelist from a review
doc: rules
---

Settle a value for good without leaving the review: every candidate row now carries a **Blacklist** and a **Whitelist** button beside its type picker — blacklist it and it is masked in every project, whitelist it and no detector flags it again. A value belongs to one list at a time, so listing it leaves just the button that takes it back off. The Rules screen calls the two lists by those names too, each with its own mark.

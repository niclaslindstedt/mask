# Masking a document

Drop a PDF or a text file onto a project, or paste text straight in. Mask reads
the text and marks everything that looks like personal data: names, street
addresses, cities, postal codes, phone numbers, personal identity numbers,
e-mail addresses and organisation numbers. A built-in list of the common
Swedish given names, surnames and localities, and check-digit verification of
the numbers, keep the guesses honest.

You confirm every replacement. Untick a false positive, change the kind of a
value, or add something the detectors missed, by typing it or by selecting it
in the preview. Then press **Confirm and mask**: each ticked value becomes a
placeholder, in the style you chose, and the masked text is ready to copy into
your LLM.

A project remembers its placeholders. The next document you add to the same
project reuses them, so the same person is the same placeholder everywhere,
and a value you rejected stays rejected. When the answer comes back, paste it
into **Restore** and every placeholder turns back into the real value — on
your device only. Nothing you upload or paste ever leaves the browser.

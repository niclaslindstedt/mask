# `src/generic/` — framework candidates

Everything in this folder is written to the framework's rules — no app domain
names, no store, labels injected, zero runtime dependencies beyond what the
framework already peers — so it can be lifted into
[`@niclaslindstedt/oss-framework`](https://github.com/niclaslindstedt/oss-framework)
unchanged when a second app needs it. App code (`src/app/`) may import from
here; nothing here may import from `src/app/`.

| Module                                          | What it is                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`placeholders.ts`](placeholders.ts)            | Placeholder naming schemes (`AAA`, `aaa`, `$1`, `KIND1`, `[KIND 1]`, `{{kind1}}`) — format one, mint the next unused one.                                                                                                                                                                                                                                       |
| [`textScan.ts`](textScan.ts)                    | Regex + literal scanning over a text into typed spans, overlap resolution, and non-overlapping span substitution (both directions).                                                                                                                                                                                                                             |
| [`checkDigit.ts`](checkDigit.ts)                | Luhn (mod 10) check-digit validation.                                                                                                                                                                                                                                                                                                                           |
| [`extractText/`](extractText)                   | File → text: text-like files read directly, PDFs through a lazily-loaded `pdfjs-dist` chunk, a geometry-driven reflow, and a style pass that writes the page's headings, emphasis and furniture back out as Markdown. Word files through `docx.ts`, which translates the package's own XML — styles, runs, numbering, tables — rather than inferring any of it. |
| [`zip.ts`](zip.ts)                              | Reading a ZIP archive: its central directory, and one member inflated through the platform's own `DecompressionStream`. Half the document formats in the world are a ZIP with XML inside.                                                                                                                                                                       |
| [`xml.ts`](xml.ts)                              | A small XML reader — elements, attributes, text, comments, CDATA, character references — for the callers that run where `DOMParser` does not.                                                                                                                                                                                                                   |
| [`pdf/`](pdf)                                   | PDF both ways: a pure typesetter plus the jsPDF writer that paints a Markdown document into one, and a `pdfjs-dist` reader that paints an existing one's pages onto canvases.                                                                                                                                                                                   |
| [`blobVault.ts`](blobVault.ts)                  | A keyed store of binary blobs in IndexedDB, best-effort throughout — a browser that refuses it answers "nothing stored" rather than throwing.                                                                                                                                                                                                                   |
| [`htmlComments.ts`](htmlComments.ts)            | Markdown's only comment is HTML's: write a line as one (hyphen runs spaced out so the body can't close it early), spot a line that is one, read what it says.                                                                                                                                                                                                   |
| [`pinchZoom.ts`](pinchZoom.ts)                  | Two fingers on an element — or a trackpad's pinch — as the zoom they ask for, about the point between them, for an app whose viewport turns the browser's own pinch off.                                                                                                                                                                                        |
| [`softKeyboard.ts`](softKeyboard.ts)            | Open a touch device's keyboard for a field that mounts a tick later, plus the soft-keyboard hints a short text field wants.                                                                                                                                                                                                                                     |
| [`collapseOnScroll.ts`](collapseOnScroll.ts)    | Collapse a scroll container's header once the reader is past it, on two thresholds so the collapse can't loop.                                                                                                                                                                                                                                                  |
| [`components/FileDropZone.tsx`](components)     | Drop target + browse button over the framework's `useFileDrop`, foldable into a single row.                                                                                                                                                                                                                                                                     |
| [`components/StringListEditor.tsx`](components) | Add / remove a list of strings.                                                                                                                                                                                                                                                                                                                                 |
| [`components/GlyphButton.tsx`](components)      | The framework's `IconButton` with its label drawn beside the glyph once the screen is wide enough for it.                                                                                                                                                                                                                                                       |
| [`components/SpanText.tsx`](components)         | Render a text with typed spans highlighted (and clickable).                                                                                                                                                                                                                                                                                                     |
| [`components/CopyablePane.tsx`](components)     | A read-only text pane with a copy button and a character count, optionally drawing its text through a renderer of the caller's.                                                                                                                                                                                                                                 |
| [`components/MarkdownText.tsx`](components)     | A read-only block of Markdown, rendered formatted through the framework's parser and line renderer.                                                                                                                                                                                                                                                             |
| [`components/DownloadMenu.tsx`](components)     | A download button offering a choice of formats — a menu when there are several, a plain button when there is one.                                                                                                                                                                                                                                               |
| [`components/SelectOrCreate.tsx`](components)   | A `SelectPicker` ending in "something else…" — choosing it swaps the trigger for a field, and what is typed becomes the value.                                                                                                                                                                                                                                  |
| [`components/PdfView.tsx`](components)          | A PDF shown as its pages: fitted to the column, pinchable, painted as pages come into view and dropped as they leave.                                                                                                                                                                                                                                           |
| [`components/Fullscreen.tsx`](components)       | A pane taken over the whole app viewport and given back — a portalled layer plus the header toggle, since iOS grants the Fullscreen API to video and nothing else.                                                                                                                                                                                              |
